# Sample outputs

Real `/v1/eeg/biomarkers` responses captured from a live service against a 30-second × 4-channel synthetic EDF (generated by `skybrain-generate-edf`). Provided so a reviewer can inspect what the API actually returns *without installing anything*.

| File | `biomarker_set` | SDK call | Size | Warm-cache latency |
|---|---|---|---|---|
| `biomarkers-spectral-output.json` | `spectral` | `compute_features(recording, profile)` | 22 KB | ~125–195 ms |
| `biomarkers-qc-output.json` | `qc` | `compute_qc(recording)` | 0.7 KB | ~5–15 ms |
| `biomarkers-full-output.json` | `full` | `run_analysis(recording, profile)` | 37 KB | ~140–250 ms |

## What's in each

- **`spectral`** — per-channel band powers (delta/theta/alpha/beta/gamma), relative band powers, peak frequencies, total power, beta/alpha and theta/beta ratios, Hjorth parameters, sample entropy, permutation entropy. Plus per-window time series. This is the fastest "I want to know cognitive state right now" call.
- **`qc`** — pass/fail summary, channel-by-channel quality scores, list of issues (line noise, saturation, flatlines, amplitude excursions). The "is this recording usable?" check.
- **`full`** — `run_analysis` complete output: QC report, full feature set, segment metrics, recording metadata, profile hash for reproducibility, SDK version.

## Reproducing these locally

```bash
skybrain-generate-edf --output samples/demo --duration 30 --channels 4 --pre-duration 10 --post-duration 10
python -m service.main
# then in another shell — see ../USER_GUIDE.md for the per-shell command
```

## Known issue — `cognitive` set not captured here

`biomarker_set: "cognitive"` is documented in the API but doesn't have a sample here. The adapter currently passes the `EegRecording` object directly to `skybrain_sdk.cognitive_metrics.compute_all_scores`, which raises `AttributeError: 'EegRecording' object has no attribute 'get'` — the SDK function expects a different argument type (likely a feature dict or DataFrame, not a Recording). Adapter fix scheduled for Phase 1 week 5-6 alongside the BCI classifier wiring; the working three sets above already exercise `compute_features`, `compute_qc`, and `run_analysis`.
